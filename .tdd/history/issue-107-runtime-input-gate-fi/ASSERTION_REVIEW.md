# Independent test-author boundary audit

The test author and provider implementer are separate agents. The61-test oracle was derived from the agreed public contract and frozen before implementation. This audit does not claim an additional third-party review of the test author's own work.

- Production binding tests obtain the actual `PreSubmissionCheckProvider` bean from `PrecheckProviderConfiguration`; no replacement provider is installed. Real environment/property binding, defaultOFF, malformed boolean and ignored arbitrary verification flags are observed. An injected transport interceptor captures canonical requests before any socket.
- Loopback assertions check full count/generation tree equality, including system instructions, schema, original Unicode text and interpretation context. Count4096 is accepted;4097 and malformed/nonintegral/duplicate counts are rejected before generation. No byte-to-token estimate is used.
- Request/refusal cases assert both server-observed exchanges and bounded per-operation attempt counters. Redirects, server errors, connection failure and trickled responses are covered. Existing18 legacy synthetic tests retain their exact fingerprints and semantics.
- Runtime usage assertions distinguish known zero from missing/invalid values. Unknown is recorded once per kind; count never fills missing generation usage. Valid known usage remains observable on rejected finish/verdict/cap results. Usage meter tags contain only bounded operation/kind values.
- RR06 observes the15-second call ceiling without a15-second wait. RI13 separately exercises a single1-second budget across two600ms synthetic stages. The fresh-stage-deadline mutation was detected by an actual assertion failure.
- External legacy attempts are denied by a scoped ProxySelector before routing during the RED/FI safety harness. The implemented endpoint rejection passes before that selector is reached. No live endpoint, credential or paid request was used.
- Six post-implementation mutations demonstrated detection of OFF bypass, over-limit count admission, changed thinking level, changed output cap, a fresh generation timeout and suppressed unknown usage. Each original production file was restored byte-for-byte; the unchanged79 tests passed afterward. This is distinct from the original chronological RED.

No assertion proves semantic model accuracy, live API/profile support, token-count/billed-input equality, actual billing or a10won cost bound. Those remain outside this synthetic verification. Root's unrestricted mandatory gate and separate final source review are separate evidence.
