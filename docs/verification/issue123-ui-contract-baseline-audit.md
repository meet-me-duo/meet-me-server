`PreSubmissionCheckService.cancel` changes status/version but retains question. `snapshot` returns that question whenever the room is open regardless of status; JDBC update persists it. `SubmissionCheckPanel` derives question without status, renders its actions, hides “내 조건 수정” when question exists, and direct submit uses ANSWER. This is source-confirmed static reasoning, not a new test execution.
