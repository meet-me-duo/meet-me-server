# 게시 대기 이슈

대상: `meet-me-duo/meet-me-server`. 두 생성 요청 모두 자동 승인 심사에서 거절됐으며 이슈는 생성되지 않았다. 최신 요구 이후의 두 번째 거절 사유는 구현·develop/main 병합 승인이 별도 이슈 게시의 구체 승인까지 포함하지 않는다는 것이었다. 추가 재시도·우회는 하지 않는다.

2026-10-28 재조회한 열린 이슈는 #154, #153, #130, #123, #110, #107이며 동일한 오류 해결 이슈는 없다. #107/#123/#130은 관련 상위 작업이다. 최초 거절 제목은 `fix: 넓은 시간 조건의 불필요한 제출 전 수정 요청 개선`이었다.

## 최신 게시 제목

fix: 넓은 시간 조건의 오탐과 직접 수정 안내 보완

## 게시 본문

### 문제

제출 전 확인에서 넓지만 명확한 시간 조건을 직접 수정 대상으로 돌릴 수 있고, NEEDS_EDIT 화면에는 무엇을 보완해야 하는지 안내가 없습니다.

### 재현 방법

개인정보 없는 합성 입력으로 넓은 오후 가능 범위, 같은 문맥의 시간대, 실제 오전/오후 모호성, 필수 개인 정보 부족을 비교합니다.

### 기대 동작

넓고 명확한 조건은 통과시키고 실제 모호성만 안전하게 질문합니다. 직접 수정이 필요하면 검증된 구체적 안내를 본인에게만 표시합니다. 기존 세 verdict는 유지하며 원문 자동 변환·사실 추측·무조건 CLEAR는 도입하지 않습니다.

완료 조건은 독립 회귀 및 검토, 전체 품질 게이트, PR/CI와 develop/main 통합, 다른 배포와 직렬화한 실제 운영 반영 확인입니다.

### 증거

기존 제품 계약은 ADR-053/054/059와 PR120입니다. 관련 추적 #107. 합성 평가와 변경 검증 근거를 PR에 연결합니다.

### 환경

meet-me-server의 제출 전 개인 확인과 Luna Structured Output 경로
