# Browser observer and local Docker boundary (test tooling)

`createBrowserObservation(allowedOrigins)` returns `{wrapContext(context),snapshot()}`. wrapContext returns the same context and wraps context plus existing/future page public route/routeFromHAR/routeWebSocket methods once. Each attempted routing registration increments routesIntercepted before forwarding original this, exact arguments, return value and thrown error unchanged. No interception is introduced. Context request events and page websocket events compare their URL origin to the exact allowed-origin set; malformed/unapproved origins increment unexpectedOrigins. Only numeric `{routesIntercepted,unexpectedOrigins}` is returned/persisted, never URLs, arguments, headers, bodies or cookies. Duplicate context/page notifications never duplicate counting. Existing certificate-manager setup occurs in the unchanged original fixture before its returned context can be wrapped; original fixture source is separately pinned and audited. Browser integration and observer unit tests are separate proofs.

The runtime bridge stages original fixture bytes unchanged as original-fixtures.ts and exports extended test/expect through fixtures.ts. Allowed origins are only the pinned localhost HTTPS origins and exact dynamic loopback synthetic identity origin. It observes/forwards existing behavior and does not fulfill, rewrite, retry or synthesize API/OPTIONS responses.

`validateLocalDockerTarget(evidence)` returns `{local:true}` only for a local selected CLI endpoint. Fields: environmentHost/environmentContext/tlsVerify/certificatePath are null or strings; empty optional strings mean unset. contextEndpoint is required. Nonempty environmentHost and contextEndpoint must both be approved: exact unix:///var/run/docker.sock or unix:///run/docker.sock, or tcp/http/https URL whose literal authority host is localhost,127.0.0.1,[::1]. Userinfo, query, fragment and non-root path are forbidden. Encoded/shorthand IP and hostname-prefix tricks are rejected. Unknown socket paths, remote/SSH/npipe/wildcard addresses and nonempty TLS_VERIFY/CERT_PATH are rejected. Invalid input throws Error.code LOCAL_DOCKER_REQUIRED. Docker metadata inspection must precede any Docker API/Testcontainers operation. No real credentials, context switch or global Docker/trust mutation is permitted. This proves the endpoint boundary; a local tunnel's ultimate daemon identity is outside what endpoint syntax can establish. Containers must use already-local pinned images and never pull remotely.

Independent scope: observer6 and Docker20 tests are new synthetic deterministic tool contracts; no browser success, actual Docker operation, model/OAuth quality or paid invocation is implied.
